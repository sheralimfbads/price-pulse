Dataset notes

  • Source: official Uzbekistan statistics JSON for selected goods, monthly average prices in UZS per kg.
  • Product codes are identifiers. Leading zeros such as 001 and 0070 are preserved.
  • Source zeros are kept for audit and marked zero_marked_unavailable. Analytical price is missing, not replaced with a fabricated value. This is a project assumption, not a confirmed publisher encoding rule.
  • Missing source values stay missing. The application does not impute prices.
  • This interface reads PostgreSQL analytics. It does not download or reload the source on each page view.
